# Academic homepage template

This site adapts Jon Barron's public academic website:

- Original site: https://jonbarron.info/
- Source: https://github.com/jonbarron/jonbarron.github.io
- Base stylesheet: https://raw.githubusercontent.com/jonbarron/jonbarron.github.io/master/stylesheet.css
- Retrieved: November 14, 2026

The original repository README states: “Feel free to clone this code for your own personal use.”

`stylesheet.css` is the original base stylesheet. The HTML retains the page, biography, section, and paper-list structure, with Shihao Wang's own content. `styles.css` supplies the text-only publication layout, responsive adjustments, and the compact Dota 2 section. No original person's biography, portrait, publications, or analytics are used.

Template provenance is retained in this source document. The visible footer attribution was removed at the site owner's request; the original README's personal-use permission does not require it. No separate MIT license is asserted for this template.

The Dota 2 Immortal medal is referenced directly from OpenDota's public assets:
https://www.opendota.com/assets/images/dota2/rank_icons/rank_icon_8.png
Its numerical leaderboard overlay follows the presentation in OpenDota's open-source player header (https://github.com/odota/web). Dota 2 game artwork belongs to its respective rights holders; no separate license for that artwork is asserted here. Hero portraits and the player's avatar are referenced from the Steam CDN URLs returned by OpenDota.
